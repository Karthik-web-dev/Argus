# Argus

Argus is an autonomous QA agent concept. This repository currently contains its static marketing page in `packages/ui`; the agent backend is intentionally not part of this landing page implementation.

## Run the UI

```sh
pnpm install
pnpm dev
```

The page is available at `http://localhost:3000`. Use `pnpm lint` and `pnpm build` to check the UI package.

## Original image assets

Procedural landscape backgrounds are generated by `scripts/generate_backgrounds.py`. Their sources and licensing are recorded in `packages/ui/public/images/CREDITS.md`.
